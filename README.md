## 📌 Overview

This is my personal portfolio website showcasing my projects, technical skills, achievements, contact details, and more. It’s built using **HTML, CSS (Tailwind), and JavaScript** with smooth animations and dark/light mode support.

---

## ✨ Features

- 🎨 Dark/Light theme toggle with logo swap  
- 📜 Resume download (with click tracking)  
- 📂 Project highlights with GitHub links  
- 💼 Skills & Achievements section  
- 📫 Contact form (Google Apps Script based email handler)  
- 📈 GitHub stats integration  
- ⬇️ Typing effect with loading screen on entry  

---

## 🛠 Tech Stack

- HTML5  
- Tailwind CSS  
- JavaScript  
- Google Apps Script (for contact form emails)  
- GSAP + Locomotive Scroll (animations)
