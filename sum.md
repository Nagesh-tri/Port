# 📘 Project Summary: Nagesh Tripathi - Portfolio Website

## 🎯 Objective
To build a personal portfolio website for Nagesh Tripathi to showcase skills, projects, GitHub stats, achievements, and contact information in a modern, responsive, and engaging manner.

---

## ✅ Key Features Implemented

- **Live Deployment**: Hosted on Vercel at [nageshtri.vercel.app](https://nageshtri.vercel.app)
- **Dark/Light Mode Toggle**: With icon change and logo swap using localStorage to remember preference
- **Responsive Design**: Optimized for all screen sizes (mobile, tablet, desktop)
- **Smooth Animations**: GSAP + Locomotive Scroll for interactive and animated sections
- **Resume Integration**:
  - Resume hosted on Google Drive (with Bitly shortened trackable link)
  - Added force download using Google Drive direct link method
  - Styled resume buttons distinctively with hover and highlight behavior
- **Skills & Projects**: Reorganized and visually balanced using Tailwind/CSS grid
- **GitHub Stats**: Integrated GitHub activity, streak, and top languages
- **Contact Form**:
  - Uses Google Apps Script to send emails (to self and acknowledgment to sender)
  - Includes BCC handling and error messages
- **Typing Loader Effect**: Displayed on first load with dynamic percentage and typewriter animation
- **Scroll to Top Button**: Floating action button appears on scroll to return to top
- **Favicon**: Custom ‘N’ based favicon generated and implemented
- **Image Optimization**: Logos adjusted for theme and PNGs with transparent backgrounds used
- **Theme-aware Logo**: Automatically switches between dark and light logo images

---

## 🧾 Tools & Technologies Used

- HTML5, Tailwind CSS, Vanilla JavaScript
- GSAP + Locomotive Scroll (Animations)
- Google Apps Script (Email Handling)
- Bitly (for trackable resume links)
- GitHub (Version Control)
- Vercel (Deployment)
- Photoshop/Image AI (Logo/PNG edits)
